# TICO — learn Python by helping Egypt

TICO is a bilingual programming game for children and undergraduates. Learners write real Python in the browser to solve recognizable Egyptian problems: organizing a public bakery queue, dispatching passengers at a railway station, and coordinating Cairo traffic lights.

The product combines a fixed, pedagogically reviewed Python curriculum with adaptive scaffolding and AI-generated mission variations. TICO, a friendly orange robot, is the single companion and in-world voice. Generated content is always constrained by approved world manifests and validated before it reaches a learner.

## Local development

The implementation is being built incrementally. Current client commands are:

```bash
cd client
pnpm install
pnpm db:generate
pnpm dev
```

The client environment template is `client/.env.example`. Never commit real credentials. AI service setup belongs in `ai-backend/README.md` as that scaffold is implemented.

## Product baseline

- Required account: email/password or Google sign-in; no anonymous mode.
- Arabic (`ar-EG`) and English (`en`), with RTL UI and permanently LTR code/output.
- Full coding workspace on laptops and landscape tablets; phones expose content and progress only.
- Python executes locally in a sandboxed Pyodide Web Worker.
- Three launch worlds, six curriculum missions per world.
- No ads, public chat, competitive leaderboard, lives, or pay-to-progress mechanics.
- AI proposes; deterministic rules and validation decide. Mastery scores are never generated by a model.

## Deployment target

- Next.js: Vercel
- PostgreSQL, authentication, and object storage: Supabase
- Python AI service: AWS EC2 baseline, portable to Render or another container host
